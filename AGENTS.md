# Инструкция для ИИ-агентов

- Прочитайте README.md и соответствующие исходные файлы перед изменениями; сохраняйте существующее поведение и локальные изменения пользователя.
- Это клиент Vite + Capacitor, без собственного сервера. UI и запросы провайдеров находятся в `src/main.js`, генерация проекта — в `src/project.js`, интеграция GitHub — в `src/github.js`.
- Запускайте `npm ci`, `npm test` и `npm run build`. Android APK требует JDK 21 и Android SDK; см. README.
- Не добавляйте ключи, токены и другие секреты в репозиторий или сообщения. Не отправляйте файлы пользователя третьим сторонам без явного действия пользователя. Учитывайте ограничения CORS и разных моделей.
- Пользователь предпочитает изменения в main. Соблюдайте ограничения текущей среды и правила защиты веток: если прямой push в main запрещён, работайте в разрешённой ветке и предложите pull request; не обходите ограничения.
- Тестируйте изменения и честно сообщайте, что не удалось проверить. Не утверждайте, что приложение выполняет код или изменяет репозитории, если соответствующая функция отсутствует.
