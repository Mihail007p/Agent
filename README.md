# Agent — AI-ассистент для Android и браузера

Русскоязычный клиент для API-провайдеров, выбранных владельцем приложения. Адаптивный интерфейс работает в браузере и в Android WebView на Capacitor 7.

## Возможности

- Встроенные подключения: Cloudflare Workers AI, OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, DeepSeek, Mistral, xAI, Together AI, Fireworks AI, Perplexity и Cerebras.
- Свой OpenAI-compatible endpoint: HTTPS-адрес, API-ключ и ID модели, доступной вашему аккаунту.
- Несколько локальных чатов, настраиваемый system prompt, Markdown и копирование ответов.
- Подключение GitHub: просмотр до 100 репозиториев и выбор текстовых файлов в чат (без изменения файлов и push). Fine-grained token с Contents: Read-only хранится только в памяти страницы; выбранный файл попадёт в локальную историю и к выбранному AI-провайдеру.
- Вложения в чате: текстовые файлы, снимки JPEG/PNG/GIF/WebP, PDF через Gemini или Anthropic. Кнопка скрепки и вставка снимка из буфера обмена. До 4 файлов по 1 МБ. Для изображений нужна модель с поддержкой vision; не все провайдеры принимают изображения в указанном формате. Неподдерживаемые двоичные файлы (например ZIP и DOCX) не отправляются. Вложения сохраняются в локальной истории и отправляются провайдеру вместе с последующими сообщениями чата.
- **«Создать проект»**: план и последовательная генерация до 30 текстовых файлов. Уже созданные исходники передаются модели в ограниченном бюджете контекста, чтобы согласовать имена и экспорты.
- Остановка генерации и ZIP с уже готовыми файлами, в том числе после ошибки.Небезопасные пути, повторы и файлы с ошибками исключаются из архива.
- В Android ZIP записывается во временный каталог приложения и открывается через системное меню **«Сохранить / отправить ZIP»**. Выберите «Файлы», диск или другое приложение. В браузере используется обычное скачивание.

## Запуск в браузере

Нужен Node.js 22 (для разработки поддерживается Node.js 20.19+):

```bash
npm ci
npm run dev
```

Откройте адрес Vite, нажмите ⚙, выберите провайдера и добавьте свой API-ключ. Production-сборка и проверки:

```bash
npm test
npm run build
npm run preview
```

### Cloudflare Workers AI

В настройках выберите Cloudflare Workers AI, укажите Account ID из панели Cloudflare, API Token с разрешением Workers AI Read и ID доступной модели. Каталог текстовых моделей загружается автоматически после ввода данных; выберите модель в списке и сохраните настройки. Переключать найденные модели можно также в верхнем меню чата. Каталог не подтверждает право на запуск каждой модели: кнопка «Проверить модель» после подтверждения отправляет короткий запрос, который может расходовать платные ресурсы. Для снимков выберите модель, поддерживающую изображения. В Android запросы к Cloudflare отправляются через нативный HTTPS-клиент, без ограничений CORS WebView; в браузере может понадобиться собственный прокси. Отмена останавливает ожидание в интерфейсе, но уже отправленный нативный запрос может продолжить выполняться и расходовать ресурсы. Наличие в каталоге не означает, что модель действительно доступна аккаунту.

## Сборка и установка APK

Нужны **JDK 21**, Android SDK Platform 35 и Build Tools. Java 17 не подходит: Capacitor 7 генерирует исходники с Java 21. Локальная сборка:

```bash
npm ci
npm run android:apk
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённый телефон с включённой отладкой по USB:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Либо откройте `android/` в Android Studio, синхронизируйте Gradle и выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

### GitHub Actions

Workflow `.github/workflows/android-apk.yml` запускается при изменении приложения или вручную через **Actions → Build Android APK → Run workflow**. Он использует JDK 21 и Node.js 22, запускает тесты, собирает web/Android и загружает APK в артефакт **Agent-debug-apk**. Артефакты хранятся 30 дней; для скачивания нужен вход в GitHub. При ошибке дополнительно сохраняется `Android-build-diagnostics`.

Это **debug-сборка для личного тестирования**, не подписанный release для магазина. Для публикации нужен собственный release keystore. Никогда не добавляйте его или пароли в репозиторий.

### Актуальная сборка APK

Откройте [последние запуски Build Android APK](https://github.com/Mihail007p/Agent/actions/workflows/android-apk.yml), выберите успешный запуск для ветки `main` и скачайте артефакт **Agent-debug-apk**. Распакуйте ZIP и установите `app-debug.apk` поверх старой версии. Для скачивания требуется вход в GitHub; артефакты хранятся 30 дней. Старая сборка 1.1.0 может не содержать новых провайдеров.

## Проверки

`npm test` проверяет безопасные пути, лимит и разбор плана, дедупликацию, обработку блоков кода, контекст генерации, содержимое ZIP и base64-экспорт. Эти проверки не обращаются к платным API.

Дополнительно в Chromium проверены настройки, чат и история, экранирование Markdown, генерация проекта, содержимое скачанного ZIP, остановка и ошибка с сохранением частичного результата, мобильная вёрстка. Ответы провайдера в браузерной проверке имитировались. Реальные API-аккаунты, системное меню сохранения на физическом Android и установка APK на устройство не проверялись.

## Ограничения и приватность

- Agent — независимый клиент, не копия ChatGPT. API-ключ, подписка и баланс не включены. Стоимость, лимиты и доступность моделей определяет провайдер; полностью безлимитной генерации нет.
- Приложение создаёт исходники и архив, но **не выполняет и не тестирует сгенерированный код**, не получает доступ к другим репозиториям и не изменяет их. Проверяйте созданный проект перед запуском.
- Контекст модели конечен. В проектный режим передаётся не более 24 000 символов уже созданных файлов; большие проекты могут требовать ручной доработки. После ошибки повторный запуск начинает новый проект; сначала сохраните готовые файлы.
- Ключи и чаты сохраняются в локальном хранилище браузера/WebView, **без отдельного шифрования**. Не используйте чужое устройство. Очистка данных приложения удаляет локальные ключи и историю. Android backup приложения отключён.
- Запросы идут напрямую выбранному провайдеру. Некоторые API блокируют браузерные/WebView-запросы по CORS: для них нужен собственный серверный прокси. Секретный production-ключ нельзя встраивать в публичный клиент.
- Произвольные endpoints должны использовать HTTPS. Наличие адаптера не гарантирует доступ к каждой модели вашего аккаунта.
