# Agent — AI assistant для Android и браузера

Agent — русскоязычный чат-клиент, который подключается к API-провайдерам, выбранным владельцем приложения. В репозитории есть адаптивный web-интерфейс и Android-проект на Capacitor.

## Возможности

- Готовые подключения: OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, DeepSeek, Mistral, xAI, Together AI, Fireworks AI, Perplexity и Cerebras.
- Дополнительные сервисы с OpenAI-compatible API: укажите базовый URL, API-ключ и ID доступной модели.
- Настраиваемые модели и system prompt.
- Несколько локально сохранённых чатов, Markdown-ответы, копирование и быстрые шаблоны.
- Режим «Создать проект»: модель составляет план и генерирует до 30 текстовых файлов по очереди, затем Agent собирает их в ZIP. Генерацию можно остановить и скачать уже готовые файлы.
- Ключ и история хранятся в локальном хранилище приложения/браузера; запросы уходят напрямую выбранному провайдеру. Не используйте общедоступное устройство для сохранения секретных ключей.

> Это независимый AI-клиент, а не копия ChatGPT и не сам OpenAI. Он не включает модели или API-подписки: нужен действующий API-ключ, а стоимость, доступность моделей и лимиты определяет провайдер. «Безлимитной» генерации не бывает: контекст и объём ответа ограничены моделью и тарифом; проектный режим сейчас ограничен 30 файлами за один запуск. Agent формирует ZIP, но не запускает сгенерированный код, не проводит тесты и не может самостоятельно менять внешний GitHub-репозиторий. Нельзя гарантировать буквально все существующие модели: у разных сервисов разные API, условия доступа и форматы. Добавляйте совместимые endpoints или расширяйте адаптеры в `src/main.js`.
>
> Веб- и WebView-клиент обращается к API напрямую. Некоторые провайдеры не разрешают запросы из браузера (CORS); для таких сервисов потребуется собственный серверный прокси. Никогда не встраивайте секретные production-ключи в публичное приложение.

## Запуск в браузере

```bash
npm install
npm run dev
```

Откройте адрес Vite, выберите провайдера в ⚙ и добавьте API-ключ. Production-сборка: `npm run build`.

## Сборка APK

Нужны Node.js 20+, JDK 17, Android Studio/Android SDK (SDK Platform 35 и Build Tools) и Android platform tools. Откройте каталог `android/` в Android Studio, дождитесь синхронизации Gradle, затем выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Для командной сборки из корня проекта:

```bash
npm install
npm run android:apk
```

Debug APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Для установки используйте Android Studio или `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`. Для публикации в магазине соберите и подпишите release-вариант собственным ключом.

В `.github/workflows/android-apk.yml` добавлена GitHub Actions сборка: runner устанавливает JDK и Android SDK, собирает debug APK и публикует его как workflow artifact `Agent-debug-apk`. Запустить её можно вручную на вкладке **Actions → Build Android APK → Run workflow** либо push-ем изменений в соответствующие файлы.

В этой среде нет установленного JDK/Android SDK, поэтому APK здесь не собран; Android-проект и workflow для сборки в GitHub включены в репозиторий.
