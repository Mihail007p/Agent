НАСТРОЙКИ

Провайдеры и модели

Добавьте API-ключ выбранного сервиса. Поддерживаются встроенные интеграции и совместимые API.

⌄

Для произвольного сервиса выберите «OpenAI-compatible» и укажите базовый URL.

Токену необходимо разрешение Workers AI Read.

Ключ хранится локально в браузере/приложении и отправляется только выбранному провайдеру.

Каталог загружается автоматически после ввода ID и токена. Проверка модели делает короткий платный запрос.

Можно указать любую модель, доступную вашему аккаунту.

♢Приватность прежде всего
Не вводите ключ на чужих устройствах. Очистите данные приложения, чтобы удалить сохранённый ключ.
ИНТЕГРАЦИЯ

GitHub проекты

Подключите GitHub, чтобы выбрать текстовые файлы репозитория и добавить их в чат. Изменение файлов и push пока не поддерживаются.

Создайте токен с доступом Contents: Read-only к нужным репозиториям. Токен хранится только до закрытия страницы. Выбранные файлы отправляются AI-провайдеру и сохраняются в истории чата.

Создать проект по идее

Опишите результат своими словами. Агент составит план файлов, затем сгенерирует их по очереди и соберёт ZIP-архив.

Для генерации нужен API-ключ провайдера. Длинная генерация делает много отдельных запросов и расходует токены/деньги по тарифу модели.
